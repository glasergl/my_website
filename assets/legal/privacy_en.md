## Data Processing When Visiting This Website

No personal data is collected or processed when this website is accessed.
To provide the website and to measure traffic volume, only the following data is temporarily stored in a log file:
- anonymized IP address
- Name of the file accessed and amount of data transferred
- Date and time of the request
- Request details and destination address (protocol version, HTTP method, referrer, user agent string)
- Indication of whether the request was successful
It is therefore not possible to identify specific individuals.

No web analytics services are used.
